# Workloom

Workloom 是一款本地优先的 Windows 工作记录与效率管理应用，帮助用户集中管理 Todo、
日报、每周重点、反思记录、月度目标和工作看板。

## 主要功能

- Todo 新增、编辑、完成、延期与自定义标签
- 日报、明日计划、备注与反思记录
- 本周重点、周报与月报回顾
- 月历颜色标记、月度目标和分类看板
- Word / PDF 报告导出
- 本地 SQLite 数据存储与自动备份
- 通过 OneDrive、WPS、百度网盘等本地同步文件夹进行个人云盘同步
- 森林绿、雾灰、沉静蓝、柔和玫瑰四种界面主题

## 数据与隐私

Workloom 采用本地优先设计。Todo、日报及其他工作数据默认保存在当前设备中。
个人云盘同步通过用户自行选择的本地同步文件夹完成。

请勿向 GitHub 提交个人数据库、备份文件或导出的工作报告。详细说明见
[PRIVACY.md](PRIVACY.md)。
